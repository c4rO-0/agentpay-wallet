# Security Policy

## Supported Versions

AgentPay Wallet has no production release. The current technical-validation
code has completed a mock-token real-Safe Anvil flow, but it is unaudited and
must not protect real user funds.

## Reporting A Vulnerability

Do not open a public issue containing a suspected vulnerability, exploit,
private key, keystore, unlock secret, capability token, signed commitment, user
identity, or private request/output data.

Use GitHub private vulnerability reporting for this repository when it is
available. If it is unavailable, email **agentpay@mail.c4r.fun** with a sanitized report. Do not include keys,
passwords, customer data or replayable payment payloads.

Include the affected version or commit, impact, reproducible behavior, and a
minimal sanitized proof. Never use a real customer key, Safe, commitment, or
funded order to demonstrate an issue.
